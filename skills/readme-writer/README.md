# README Writer

编写或重写仓库根目录的 README.md，中英文都支持，成品应该像一个真维护者在向别人介绍这个项目。

指令本体见 [SKILL.md](SKILL.md)。

## 适用

- 新写项目 README
- 重写或精简现有 README
- 调整 README 的结构和措辞
- 中英双语 README

不适用：架构文档、API / 参考文档、CONTRIBUTING、changelog、release notes、教程、营销页。

## 规则要点

- README 是项目门面，不是项目报告。读者要能快速看懂：项目是什么、解决什么问题、能做什么、怎么试用、去哪找更多文档
- 动笔前先看仓库和相关文档，不发明功能、命令、兼容性、性能和进度
- 用具体例子和日常语言，不堆抽象名词
- 不写报告腔：里程碑编号、交接说明、agent 指令、进度汇报式措辞都不要
- 章节只留需要的，长短不必对称
- 中文像中文技术写作，英文像正常的开发者英文

## 使用

把本目录放进你的 agent 的 skills 目录。当你要求写或改根 README 时，agent 会自动选用它。
