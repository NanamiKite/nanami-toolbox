# Engineering Documentation Clarifier

重写中英文技术文档，提高可读性，同时不改变技术含义。

指令本体见 [SKILL.md](SKILL.md)。

## 适用

- README、架构 / 设计文档、协议说明
- API / CLI 文档、安装指南、故障排查、工程笔记
- 按 ASD-STE100 风格原则改写英文工程文档

不适用：创意写作、营销文案、日常对话、代码重构，以及需要改设计本身而不是改文档的请求。

## 规则要点

- 不新增事实、结论、假设或实现细节
- 保留约束、不确定性和证据强度；must / should / may / can 的差别原样保留
- 命令、API、标识符、状态名、错误名、协议术语、路径、数字、版本、代码不动
- 术语保持一致，只在明显指同一概念时归一
- 原文有歧义时不猜

英文参考 ASD-STE100 的部分原则，不要求严格 STE 合规：句子直接、主语和条件明确、该用主动语态就用、常用词、拆开过密的长句、去掉空泛和营销式表达。

中文用对应的工程写法：句子紧凑，条件、动作、结果写明确，多用直接动词，少长定语和嵌套的“的”，去掉不必要的“进行 / 实现 / 相关 / 对应 / 相应”，技术术语保持原样。

## 使用

把本目录放进你的 agent 的 skills 目录。当你要求重写、精简或提高某份技术文档的可读性时，agent 会自动选用它。
